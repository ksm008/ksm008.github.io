[1117번: 색칠 1](https://acmicpc.net/problem/1117)

```java
import java.io.*;  
import java.util.StringTokenizer;  
  
public class Main {  
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));  
    static BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));  
    static StringBuilder sb = new StringBuilder();  
  
    public static void main(String[] args) throws IOException {  
        StringTokenizer st = new StringTokenizer(br.readLine());  
        long W = Long.parseLong(st.nextToken());  
        long H = Long.parseLong(st.nextToken());  
        long f = Long.parseLong(st.nextToken());  
        long c = Long.parseLong(st.nextToken());  
        long x1 = Long.parseLong(st.nextToken());  
        long y1 = Long.parseLong(st.nextToken());  
        long x2 = Long.parseLong(st.nextToken());  
        long y2 = Long.parseLong(st.nextToken());  
  
        long layered = Math.min(f, W - f);  
  
        long verticalSpace;  
        if (x2 <= layered) {  
            verticalSpace = (x2 - x1) * (y2 - y1) * 2;  
        } else if (x1 >= layered) {  
            verticalSpace = (x2 - x1) * (y2 - y1);  
        } else {  
            verticalSpace = (layered - x1) * (y2 - y1) * 2 + (x2 - layered) * (y2 - y1);  
        }  
  
        long totalSpace = (c + 1) * verticalSpace;  
        long result = (W * H) - totalSpace;  
  
        sb.append(result);  
        bw.write(sb.toString());  
        bw.flush();  
        bw.close();  
        br.close();  
    }  
}
```

조건을 보니 W, H의 크기가 너무 커 곱했을때 경계값에서오버 플로우가 무조건 일어난다. long으로 전부 통일시켜 진행했음.

f를 기준으로 종이를 접게 되면 완전한 2겹이 되거나, 2겹인 곳과 1겹인 곳, 그리고 그냥 1겹(그냥 뒤집기만 함)인 경우가 생긴다. 그래서 어떤 경우인지를 도출하기 위해 2겹의 끝을 알아내야 한다. 

예제 입력 1의 `5 6 2 2 1 1 3 2`인 경우, f는 2이고 W는 5다. 그러면 겹쳐지는 부분은 2줄, 남는 부분 1줄이 생길 것이다.
