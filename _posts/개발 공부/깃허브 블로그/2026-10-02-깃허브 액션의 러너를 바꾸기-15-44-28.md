오라클 클라우드의 무료 인스턴스인 Ampere A1으로 깃허브 액션 러너 설정을 해봤다.

우선 아래 작업을 통해 인스턴스에서 사전 작업을 해준다.

```
sudo mkdir -p /opt/hostedtoolcache
sudo chown ubuntu:ubuntu /opt/hostedtoolcache
sudo apt-get update
sudo apt-get install -y build-essential ruby-dev zlib1g-dev libxml2-dev libxslt1-dev
```

그 다음, github YML 파일을 수정한다. 빌드 사이트 아래에 해당 줄을 붙여넣는다. 아래 줄은 깃허브 rawimage로 조금 사이트 용량을 낮춰본 것이다. 큰 의미는 없다.

```
   - name: Replace image paths to raw URL
        run: |
          find _site -type f -name "*.html" -exec sed -i 's|"/assets/img/_blogImage/|"https://raw.githubusercontent.com/ksm008/ksm008.github.io/main/assets/img/_blogImage/|g' {} +
          find _site -type f -name "*.html" -exec sed -i 's|"assets/img/_blogImage/|"https://raw.githubusercontent.com/ksm008/ksm008.github.io/main/assets/img/_blogImage/|g' {} +
```

그리고 한번 빌드를 한 후, --incremental을 빌드에 추가하면 끝...

```
- name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0
          clean: false # false로...

      # ... (중간 단계 생략) ...

      - name: Build site
        run: bundle exec jekyll b --incremental -d "_site${{ steps.pages.outputs.base_path }}" # --incremental 달기
```
