## 개요
정보보안기사, 리눅스마스터를 공부하면서 가장 어렵고 문제가 되었던 것은 실습이다.
하지만 해당 시험들의 실기를 준비하려면 실습이 필수이며 정보보안기사의 경우 해당 상황들을 테스트하기 위한 환경 설치가 매우 까다롭다. 

제공하는 기능은 다음과 같다.
- 기본적인 정보보안기사/리눅스 마스터 1급 취득에 위한 기초 개념 지식 설명 및 문제 풀이
- 실기 대비용 파트
	- 리눅스 마스터 1급과 정보보안기사는 공통으로 둘 다 리눅스 운영체제를 사용한다. 그러므로 웹에서 리눅스 환경을 재현할 수 있어야 한다. 정보보안기사의 경우 유닉스/솔라리스 또한 제공이 가능하면 좋겠지만 굳이 싶어서 미룸.
	- 리눅스 마스터는 주로 명령어 사용 및 애플리케이션 설정과 관련한 문제들을 낸다. 이를 실습할 수 있어야 한다.
	- 정보보안기사의 경우 시스코 패킷 트레이서, 와이어샤크, 트립와이어 등 여러 프로그램을 전부 실습할 수 있어야 한다.

## 🛠️ 기술 스택 (Tech Stack)

**1. 프론트엔드 (UI & 웹 터미널)**
- **핵심 스택:** React + Vite (빠른 빌드와 모던 웹 UI 구성)
- **터미널 라이브러리:** `xterm.js` (VS Code 내장 터미널에도 쓰이는 검증된 라이브러리. 브라우저에서 완벽한 리눅스 터미널 화면을 그려줌)
- **데이터 시각화:** `Recharts` 또는 `Chart.js` (실시간 패킷 흐름을 와이어샤크처럼 표나 차트로 시각화)

**2. 백엔드 (서버 & 컨테이너 관리)**
- **핵심 스택:** Java (Spring Boot)
- **컨테이너 제어:** `docker-java` 라이브러리 (스프링 부트 안에서 자바 코드로 도커 컨테이너를 생성, 삭제, 상태 조회)
- **실시간 통신:** WebSocket / STOMP (웹 터미널의 키보드 입력값과 패킷 탐지 데이터를 지연 없이 프론트엔드와 주고받기 위해 필수)

**3. 네트워크 에이전트 (eBPF 패킷 후킹)**
- **핵심 스택:** Python + BCC (BPF Compiler Collection)
- **역할:** 서버 커널 단에서 도커 네트워크의 패킷을 낚아채서(Hooking) JSON 형태로 가공한 뒤 스프링 서버나 프론트로 쏴주는 가벼운 백그라운드 스크립트.

**4. 인프라 및 DB**
- **서버:** Oracle Cloud Ampere A1 (ARM64 아키텍처 우분투 환경)
- **가상화:** Docker Engine
- **DB:** MySQL 또는 PostgreSQL (사용자 정보, 실습 진행도, 채점 결과 저장)

## 🚀 개발 단계 (Roadmap)
### 1단계: 인프라 세팅 및 컨테이너 제어 증명 (PoC)
가장 먼저 백엔드에서 도커를 마음대로 조종할 수 있는지 확인하는 뼈대 작업이야.
- 오라클 클라우드 인스턴스에 ARM(aarch64)용 도커를 설치해.
- Spring Boot 프로젝트를 생성하고 `docker-java` 의존성을 추가해.
- 포스트맨(Postman) 같은 API 툴로 스프링 서버에 `/start-container` 요청을 보냈을 때, 오라클 서버에 실제로 알파인 리눅스(Alpine Linux)나 우분투 컨테이너가 짠 하고 생성되는지 테스트해.

### 2단계: 웹 터미널 실시간 연동 (가장 중요)
이 프로젝트의 핵심인 '설치 없는 웹 실습'을 구현하는 단계야.
- React 프론트엔드에 `xterm.js`를 띄워 까만 터미널 창을 만들어.
- 사용자가 터미널에 `ls -al`을 치면, 이 텍스트가 WebSocket을 타고 Spring Boot로 넘어가도록 연결해.
- Spring Boot는 이 입력을 실행 중인 도커 컨테이너의 표준 입력(stdin)에 꽂아주고, 컨테이너에서 나온 결과물(stdout)을 다시 WebSocket으로 프론트에 던져주는 파이프라인을 완성해.

### 3단계: eBPF 기반 실시간 패킷 탐지기 구축
터미널 옆에 와이어샤크처럼 패킷이 실시간으로 찍히는 화면을 만드는 단계야.
- 파이썬과 BCC 라이브러리를 활용해 간단한 eBPF 스크립트를 작성해. 특정 도커 컨테이너가 사용하는 가상 네트워크 인터페이스(veth)를 타겟으로 잡아 TCP/UDP 패킷의 출발지, 도착지 IP와 포트를 추출하는 스크립트야.
- 파이썬 스크립트가 잡은 패킷 데이터를 실시간으로 프론트엔드에 전달해 Recharts로 시각화해. (이때 부하를 줄이기 위해 1초 단위로 모아서 보내는 버퍼링 로직이 들어가면 좋아).

### 4단계: 실습 시나리오 구성 및 OS 전환 로직
여러 해킹 기법과 OS를 자유자재로 바꾸는 기능을 추가해.
- ARM 아키텍처와 호환되는 칼리 리눅스(Kali Linux), 우분투, DVWA 도커 이미지를 오라클 서버에 미리 풀(Pull) 받아둬.
- 프론트엔드에 '환경 선택' 드롭다운 메뉴를 만들고, 사용자가 OS를 바꿀 때마다 스프링 서버가 기존 컨테이너를 폭파하고 새 이미지를 기반으로 컨테이너를 띄워 WebSocket 세션을 부드럽게 갈아 끼우는 로직을 구현해.

### 5단계: 채점 및 오답 노트 (학습 도구 고도화)
단순한 쉘(Shell) 제공을 넘어 '캡스톤 프로젝트'로서의 가치를 높이는 마무리 단계야.
- 사용자가 특정 해킹 실습(예: SQL 인젝션으로 관리자 패스워드 탈취)을 성공했을 때, 플래그(Flag) 값을 입력받아 DB에 실습 완료로 기록해.
- 진행 과정에서 입력했던 터미널 명령어 기록을 저장해 두었다가, 취약한 부분을 분석해 맞춤형 해설이나 개선된 명령어(의사코드 기반 프롬프트)를 제공해 줘.
