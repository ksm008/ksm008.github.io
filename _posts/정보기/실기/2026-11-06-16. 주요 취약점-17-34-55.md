### (2) Bash 이해하기
#### 1) 셸 변수 선언
- **(가) 지역변수 : 선언한 셸 내에서만 사용 가능한 변수**
	- `var='local'` 처럼 쉘 안에서 지역 변수 선언이 가능함. 사용은 `echo=$var` 같이 `$`를 붙이면 됨.
	- 만약 자식 bash 프로세스를 생성하면 부모 프로세스에 선언된 지역변수는 참조 불가
	- `set` 명령은 모든 지역, 환경 변수 및 함수 목록을 반환한다. 
	- `unset`으로 제거가 가능하다.
	- `env` 명령은 환경변수 및 함수 목록을 반환한다. 지역 변수로 선언한 var는 안나옴.
- **(나) 환경변수(Environment Variable) : 자식 셸에서도 사용 가능**
	- `export VAR='Enviroment'` 형태로 선언. export를 사용한다. 
	- 변수명은 대문자로.

#### 2) 셸 함수 선언
- **(가) 함수 선언**
	- `fn() { echo "local function"; }`
	- 셸 내에서 바로 호출이 가능하지만 선언한 셸로 한정됨
- **(나) 함수의 환경변수 설정**
	- 근데 앞에 export를 붙여 환경변수로 만들면 자식 bash에서도 사용이 가능함.
	- `export fn='() { echo "environment function"; }'`
	- 이러면 fn을 입력하면 해당 함수가 실행이 된다.
- **(다) bash 셸의 함수 선언기능 취약점**
	- 만약 환경변수의 함수 선언문 뒤에 임의의 명령어를 삽입할 경우...
	- 환경변수에 설정된함수 선선 시 함수 선언의 끝을 인지하지 못하고 삽입한 명령어까지 실행하는 취약점이 존재함.
	- 이게 최초 발견된 Bash 취약점인 쉘쇼크이다.
	- `export fn='() { echo "environment function"; };echo "command"'`
	- 이런식으로 환경변수를 설정하고 한번 fn 함수를 실행한 후 자식 bash를 만들면 echo "command"가 실행된다.
