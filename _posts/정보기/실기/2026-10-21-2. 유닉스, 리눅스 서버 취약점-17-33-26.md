## 1. 계정 관리
### (1) 루트 이외의 UID 0 금지
#### 1) 개요
- 루트 계정과 동일한 UID일 경우 똑같이 root의 권한을 가지게 된다.

#### 2) 실습
- `useradd -o -u 0 -g 0 -d /root eve`
- 루트 계정으로 다른 루트 계정인 eve를 만드는 명령어.
- uid 중복을 위해 -o 옵션을 사용한다.
- 이후 id 명령, passwd 파일을 통해 UID가 0인것을 확인할 수 있다.

#### 3) 실습
- passwd 파일 안 계정들의 UID를 잘 살펴봐야 한다.
- `eve : x : 0 : ...`
- 세 번째 필드값이 UID.
- 적절한 UID로 변경하거나, 삭제하거나...
- 변경은 `usermod`로 하면 된다. 
	- **솔라리스, 리눅스, HP-UX**
		- `usermod -u 531 -g 529 -d /home/eve eve`
		- 이브의 UID를 351, GID를 529, 홈 디렉터리를 `/home/eve`로 설정한다.
	- **AIX**
		- `chuser id=100 eve`

### (2) 패스워드 복잡성
#### 1) 개요
- 멍청하게 설정하지 말라고

#### 2) 보안 설정
- **(가) 부적절한 패스워드 유형**
	- 멍청하게 하지 말라고
	- 알잘딱
	- ...설마 이거도 뭐 어떻게 설정해야 한다 이런걸 쓰도록 나오려나???
	- 사전 단어 쓰지 말기, 조합하지 말기
	- 길이가 짧거나 공백 금지
	- 키보드 자판의 일련 순 금지
	- 사용자 계정 정보에서 유추할 수 있는 단어 금지
- **(나) 패스워드 관리 방법**
	- 영문, 숫자, 특문 조합해서 8자 이상
	- 다음 문자 종류 2종류 이상 조합해서 최소 10자, 3종류 혼합하여 최소 8자리.
		- 대문자
		- 소문자
		- 숫자
		- 특수문자
	- 시스템마다 다른 패스워드 쓰고 변형하여 기록하기
- **(다) 패스워드 복잡성 설정 방법**
	- **1. system-auth 서비스 PAM 설정 파일을 이용하여 패스워드 복잡성 설정**
		- 책에서는 레드햇 기반인 페도라로 나옴.
		- 우분투는 libpam-pwquality 패키지를 깔아야 한다.
		- 모듈은 pam_pwquality.so를 사용한다.
		- 확인 경로는 `/etc/pam.d/common-password`
	- **2. 권장 설정 방식(pam.cracklib.so 모듈의 인수 권장 설정)**
		- **lcredit=-1**
			- 최소 소문자. lower case.  최소 1자 이상의 소문자를 요구하는 것.
		- **ucredit=-1**
			- 최소 대문자. upper case
		- **dcredit=-1**
			- 최소 숫자. digit.
		- **ocredit=-1**
			- 최소 특수문자. other character
		- **minlen=8**
			- 최소 길이. 
		- **difok=N**
			- 새 비밀번호가 이전 비밀번호와 달라야 하는 문자의 개수 설정.
		- 우분투의 경우...
			- `password requisite pam_pwquality.so retry=3 minlen=10 difok=3 ucredit=-1 lcredit=-1 dcredit=-1 ocredit=-1`
			- 이렇게 common-password의 값을 직접 바꿔도 되지만, 전용 설정 파일인 `/etc/security/pwquality.conf`에서 전역으로 규칙을 관리할 수 있다.
			- `requisite` 플래그는 여기서 복잡성 조건을 통과하지 못하면 뒤의 모듈을 실행하지 않고 즉시 변경 실패로 처리하겠다는 의미.

### (3) 패스워드 최소 길이 설정
#### 1) 개요
- 짧게 하지 말라고

#### 2) 보안 설정
- **OS별 정책설정 파일 위치**
	- **솔라리스**
		- `/etc/default/passwd`
	- **리눅스**
		- `/etc/login.defs`
	- **AIX**
		- `/etc/security/user`
	- **HP-UX**
		- `/etc/default/security`
	- 왜 다 다르고 지랄이지??????????????? 이 힙스터 새끼들 그냥 죽여버리고 싶네
- **(가) 각 OS별 패스워드 정책설정 파일 점검**
	- **솔라리스**
		- PASSLENGTH=8
	- **리눅스**
		- PASS_MIN_LEN 8
	- **AIX**
		- minlen=8
	- **HP-UX**
		- MIN_PASSWORD_LENGTH=8

### (4) 패스워드 최대 사용기간 설정

- **리눅스**

- **AIX**
	- maxage=12
- **HP-UX

### (6) 패스워드 파일 보호
#### 1) 개요
- 바보도 아니고 패스워드 파일을 그대로 두면 안되겠죠?

#### 2) 보안 설정
- **(가) 솔라리스, 리눅스**
	- **shadow 파일 점검하기**
		- `/etc/shadow`에 위치
	- **passwd 파일의 두번째 필드가 x인지 확인하기**
	- **패스워드 정책 변경 관련 명령어**
		- pwconv - shadow 적용
		- pwunconv - shadow 미적용
- **(나) AIX 운영체제**
	- `/etc/security/passwd` 파일 내 암호화 확인
	- 얘는 기본적으로 패스워드를 암호화한다
- **(다) HP-UX 운영체제 점검**
	- 나오면 자살함

### (7) Session Timeout 설정
#### 1) 개요
- 오랜시간 방치하면 알아서 꺼지게...

#### 2) 보안 설정
- **sh, ksh, bash**
	- `/etc/profile(.profile)`
		- TMOUT=600
		- export TMOUT
- **csh**
	- `/etc/csh.login` 또는 `/etc/csh.cshrc`
		- set autologout=10
