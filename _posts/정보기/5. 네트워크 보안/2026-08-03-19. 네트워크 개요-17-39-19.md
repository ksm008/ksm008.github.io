## 1. 개요
### (1) 데이터 통신
#### 1) 프로토콜
- **(가) 기본 개념**
	- 통신 규약. 어떻게 서로 통신할지를 정해둔 약속임.
- **(나) 주요 구성요소**
	- 프로토콜은 무엇을, 어떻게, 언제 통신할 것인가를 규정함. 주요 요소는 구문과 의미, 그리고 타이밍이다.
	- **구문(Syntax) :** 구문은 데이터의 구조나 형식, 데이터 표현 순서를 의미함.
	- **의미(Semantics) :** 의미는 비트의 영역별 의미를 나타냄. 즉, 특정 패턴을 어떻게 해석하고 그를 기반으로 어떤 동작을 할 것인가를 결정하게 됨.
	- **타이밍(Timing) :** 데이터를 언제, 얼마나 빠른 속도로 전송할 것인가를 나타냄.

>**프로토콜에 관한 측면**<br>
>- 프로토콜은 물리적 측면과 논리적 측면으로 구성된다.
>- 물리적 측면 : 데이터 전송에 사용되는 전송 매체, 접속용 커넥서 및 전송 신호 등 물리적 요서에 관한 규약. 
>	- RS-232C, V.21 등이 있음
>- 논리적 측면 : 데이터 표현 형식 단위인 프레임(Frame)의 구성, 프레임 내의 각 항목의 의미와 기능, 데이터 전송의 절차를 말함.
>	- 동일 회사 제품간에만 사용이 가능한 전용 프로토콜과 일반적으로 적용이 가능한 범용 프로토콜로 나뉨.
>	- 전용 프로토콜의 예시로는 IBM의 SNA, SDLC
>	- 후자의 경우 TCP/IP
>- 프로토콜을 제정하는 기관은 여러곳.

## 2. OSI 모델과 TCP/IP 프로토콜
### (1) OSI 모델
#### 1) 개요
- 네트워크 통신을 다루는 ISO 표준은 개방 시스템 상호연결/OSI 모델이다.
- ISO는 기구, OSI는 모델. 이 모델은 1970년 후반에 처음 소개됨.
- 개방 시스템은 기반 구조와 관계 없이 시스템 간의 통신을 제공하여 서로 다른 시스템 간의 통신을 원활하게 하는데 목적이 있음.
- 반대로 특성 사설 프로토콜을 사용해 타 회사와는 호환이 안되는 시스템은 폐쇄형.

#### 2) 계층의 구성
- 7개의 계층은 3개의 그룹으로 나눌 수 있음.
	- 제 1 물리 계층, 제 2 데이터 링크 계층, 제 3 네트워크 계층은 한 장치에서 다른 장치로 데이터를 전송할 때 필요한 물리적인을 처리함.
		- 전기적인 규격, 물리적인 연결, 물리 주소, 전송시간, 신뢰도 등
	- 제 5 세션 계층, 제 6 표현 계층, 제 7 응용 계층은 사용자 지원 계층으로 분류가 가능함. 서로 관련이 없는 소프트웨어 시스템 간의 상호 연동을 가능하게 함.
	- 제 4 전송 계층은 이 두 그룹을 연결하고 하위에서 전송한 내용을 상위 계층이 사용할 수 있는 형태가 되도록 보장함.

#### 3) OSI 모델의 계층구조
- **(가) 물리 계층(Physical layer)**
	- 데이터를 물리 매체상으로 전송하는 역할을 담당함.
	- 개개의 비트를 한 노드에서 다음 노드로 전달하는 책임을 가짐.
	- 사용자장비와 네트워크 종단장비 사이의 물리적, 전기적인 인터페이스 규정에 초점을 둠. 전송 선로의 종류에 따라 전송방식과 인코딩 방식을 결정함.
	- 신호, 부호화, 전송방식 결정을 관리한다.
- **(나) 데이터링크 계층(Data link layer)**
	- 물리 계층의 있는 그대로의 전송 설비를 신뢰할 수 있는 링크로 변환한다. 상위 계층인 네트워크 계층에게 오류 없는 물리 계층으로 보이도록 한다.
	- 비트 동기, 흐름제어, 오류제어 기능 등을 수행한다.
	- 데이터 링크 계층은 논리적 연결제어를 담당한느 LLC(Logical Link Control) 또는 DLC(Data Link Control)와 장비와 장비 간의 물리적인 접속을 담당하는 MAC(Media Access Control)의 두 sub 계층으로 나뉘어진다.
	- 데이터링크 계층에서 다루어지는 데이터 단위를 지칭하여 일반적으로 프레임이라고 부른다.
	- **+ MAC**
		- 네트워크 인터페이스 카드(NIC)라 불리는 MAC은 유일한 식별번호를 가지는데, 이걸 MAC 주소라고 함. 24비트의 업체코드, 24비트의 제조번호로 구성됨.
- **(다) 네트워크 계층(Network layer)**
	- 송신자측에서 수신자측까지 데이터를 안전하게 전달하기 위해 논리적 링크를 설정하고 상위 계층 데이터를 작은 패킷으로 분할하여 전송하는 역할을 수행.
	- 여기서 다루는 데이터 단위는 패킷.
	- 논리주소지정, 주소변환, 다중화
- **(라) 전송 계층(Transport layer)**
	- OSI의 7계층 구조는 전송 계층을 기점으로 하위계층으로 이루어진 네트워크 서비스와 상위계층으로 이루어진 사용자 서비스로 구별될 수 있음.
	- 전송 계층은 세션을 맺고 있는 두 사용자 사이의 데이터 전송을 위한 종단간(End-to-End) 제어를 담당한다.
	- 종단간 전송은 단순히 한 컴퓨터에서 다음 컴퓨터로의 전달이 아니라, 송신 컴퓨터의 응용프로그램(프로세스)에서 최종 수신 컴퓨터의 응용 프로그램으로 전달을 의미함.
	- 상위계층과 하위계층의 예시로 공기가 하위 계층, 통용언어/언어규칙이 상위계층에 해당함.
- **(마) 세션 계층(Session layer)**
	- 세션 계층은 네트워크 대화 제어기. 통신 시스템 간에 상호대화를 설정.
	- 프로세스 사이에 세션이라 불리는 연결을 확립, 유지하며 동기화 하는 기능을 제공.
	- 프로세스에 해당하는 것으로 실제 이용자의 응용 프로그램이 있음.
	- 표현 계층으로부터 받은 데이터를 효율적인 세션 관리를 위해 짧은 데이터 단위로 나눈 후 전송 계층으로 내려보냄.
- **(바) 표현 계층(Presentation layer)**
	- 송/수신자가 공통으로 이해할 수 있도록 정보의 데이터 표현방식을 바꾸는 기능을 담당함.
	- 응용 계층으로부터 데이터를 받아서 표준 포맷으로 변환시킨다. 표현 계층에서 동작하는 프로토콜은 존재하지 않는다. 
	- 송신자측의 표현 계층은 응용 계층으로부터 받은 데이터의 보안과 효율적인 전송을 위해 암호화와 압축을 수행하여 세션 계층으로 내려 보낸다.
	-
