추석 연휴였는데 쉬지도 못하고, 월화는 연가까지 써가면서 공부를 했다. 막판 스퍼트를 좀 빡세게 함. 심지어 화요일에는 아침 6시에 배드민턴을 치고 9시에 집을 와서 다음날 아침 8시까지 공부함. 스타벅스 모카 한 병, 핫식스 2캔 마셨다.

그렇게 제정신이 아닌 상태로 시험장으로 갔다. 송파 IT관제센터라는 곳이였는데 건물 하나는 내가 봤던 CBT 시험장 중 가장 좋았다. 그리고 시험 규정도 엄격했다. 아예 물품은 수납장에 넣어둬야 했고 시험장에 들어가기 전 금속탐지기로 몸을 한번 더 수색하고 들여보냈다. 

심지어 자리 앉으니까 뭔 안면인식까지; 되게 신기한 경험이였다.

아무튼 시간이 되고 시험을 봤는데, 5과목이 아예 나뉘어져 있어 한 과목씩 풀어야 한다. 20개씩 총 5개로 나뉘어져 있음.

근데... 와 진짜 필기만 가지고 보면 이건 절대 못붙겠다 싶더라. 기출문제를 풀면서 안나왔던 범위가 나옴.

나왔던걸 좀 기억을 되살려 보자면...

- NetBIOS 포트 번호 리스트 주고 아닌 것 찾기
- 커버로스 설명 중 틀린 것 찾기
- 커버로스의 동작 절차 
- 이산대수가 아닌 공개키 알고리즘 찾기
- 세션 하이재킹의 순서
- DAC의 설명 중 틀린 것
- 프로토콜 설명 주고 맞추기 (응답코드, 헤더, 바디를 반환한다고 되어있었으니 HTTP였을것)
- HTTP에 보안을 추가한 것 찾기
- 취약점 분석 도구가 아닌 것(OLE가 껴있었음)
- Nessus 설정 파일 찾기
- pwquality.conf 편집 (첨 보는거였는데 뭔가 이거 같더라)
- 서비스의 버전을 알 수 없는 커맨드 (telnet을 사용해도 서비스 버전을 알 수 있음)
- 돌아오는 응답이 다른 네트워크 포트 스캐닝 중 하나
- umask 사용해서 파일 주인만 읽기 쓰기 실행이 되도록. 
- IP 스푸핑의 순서
- 마운트 후 나오는 파티션 중 SetU/GID 불가능한 파티션 찾기(nosuid)
- 인공지능과 관계없는 것 하나 고르기
- DNS 싱크홀 설명 나옴
- 디피-헬만 계산 중 틀린 부분 찾기 (모듈러 연산 결과가 틀린거였음)
- snort 룰 해석하기 (포트 범위가 틀렸었음)
- TFTP의 설명 중 틀린 것
- 정적/동적 분석 맞추기
- 무선랜 프로토콜 속도 맞추기(802.11g 54Mbps 이걸 맞췄네 ㅅㅂㅋㅋㅋ 뭔가 이거 같더니만)
- AES를 사용하는 무선랜 보안 기술(WPA2)
- WTLS에 대해 틀린 것
- 화면 보고 어떤 포트를 스캔하는지 (UDP 스캔하여 ICMP Unreachable이라 뜨는게 많이 나오는 화면이였음
- 오용침입탐지만 모여있는 것 하나 고르기
- SSL-VPN 비교
- 전자우편이 수신자의 발신되는 과정
- SQL Injection 공격 결과 보고 어떤 공격인지
- SET을 풀어 쓰면 뭔지(Secure Eletronic Transaction)
- 일반적인 데이터로 중요한 정보를 만들어내는 것. 추론. 집성처럼 여러 개 합치는게 아님
- 침해사고 대응 7단계 중 빈 칸 맞추기
- 디지털 포렌식의 원칙
- 슬랙 공간 종류 맞추기
