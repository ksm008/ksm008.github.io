## 1. 해킹
### (1) 해킹의 개요
#### 1) 해킹의 정의
- 다른 컴퓨터 침입해서부당행위 하는 거

#### 2) 해커의 정의
- 사이버 범죄자인 크래커와 구분되어 사용됨
- 기술 개발에 정열을 쏟는 고급 기술자

#### 3) 해커의 분류
- **(가) 수준별 분류**
	- **Elite**
		- 최고 수준 해커
		- 걍 다 뚫음
	- **Semi Elite**
		- 취약점 알고 최소한의 코드 작성이 가능한 애
	- **Develped Kiddie**
		- 해킹기법에 대해 알긴 알음
		- 취약점을 발견하거나 상황에 맞게 바꾸진 못함
	- **Script Kiddie**
		- 기술적 지식이 부족해 GUI OS 바깥 세상으로 나와본 적이 없음 ㅇㅈㄹ
		- 잘 알려진 트로이목마를 사용해 인터넷 사용자를 공격하고 다님
	- **Lamer**
		- 해커는 되고 싶지만 경험도 기술도 없는자 
		- 대중매체를 통해 해커에 대해 듣고 스스로 엘리트로 착각하는 그릇된 우월감에 빠져있음 ㅋㅋㅋㅋㅋㅅㅂ
- **(나) 기타 해커 관련 용어**
	- 화이트 햇 : 화이트 해커
	- 블랙 햇 : 블랙 해커
	- 그레이 햇 : 중도
	- 핵티비즘 : 정치나 사회적 목적을 위해 정부나 기업 등의 웹 사이트를 해킹하는 활동이나 주의.

### (2) 해킹 기법
#### 1) 해킹기술의 변화
- 1990년대 초기엔 네트워크 이용 기술 공격 수준이 높지 않았고 지식이 높은 수준의 지식이 필요했으므로 침입 성공률이 낮아음
- 1990년대 말에서 2000년대에는 점점 공격 기술이 발달하며 침입자수가 급격히 증가함.
- 최근에는 금전적 이익추구 등 뚜렷한 목적을 가지고 공격하는 양상임.
- 악성 봇, 피싱, 스미싱, 홈페이지 악성코드 유포가 예시.

#### 2) 일반적인 해킹 순서
- 정보 수집
- 불법 로그인이나 트래픽 감청
- 정보를 가로채어 본인 컴으로 전송
- 시스템에 백도어 프로그램을 설치하여 쉽게 드나들거나 로그를 없애 흔적을 삭제함
- **APT(Advanced Persistent Threats, 지능형 지속해킹 공격)**
	- 사용자에게 노출되지 않은 상태에서 지속적으로 공격하여 정보 수집이나 악의적 행위를 수행함.
	- 주로 특정 대상을 목표로 하며 정치적이나 금전적 목적을 이유로 공격하는 성향을 띔.

## 2. 침해사고 대응과 포렌식
### (1) 컴퓨터 침해 대응팀
#### 1) CERT(Computer Emergency Response Team) 개요
- 해킹, 바이러스에 대항하는 보안 기술을 개발, 서비스하는 컴퓨터 응급 대응센터.

#### 2) CERT의 역할
- 침해사고 예방/대응
- 기술 연구 및 전파
- 취약점 진단 및 조치, 모니터링 교육 등
- 침해사고 예방 활동
- KrCERT/CC등 외부 기관의 대응협력 활동
- 침해사고 접수, 분석, 피해복구 등의 침해사고 대응 활동

#### 3) 사고대응 7단계 절차
- 사고 전 준비
- 사고 탐지
- 초기 대응
- 대응 전략 체계화
- 사고 조사
- 보고서 작성
- 복구 및 해결

### (2) 디지털 포렌식(Digital Forensics)
#### 1) 개요
- 다양한 디지털 장치에서 범인과 연관된 자료를 발견하고 분석하여 법적인 문제를 해결하는 작업을 의미함.
- 범죄의 증거를찾기 위해 컴퓨터, 휴대폰, 이메일, SNS, 웹, CCTV, 블랙박스, 네비게이션 등과 같은 다양한 장치의 디지털 데이터를 조사하고 분석하는 작업 등이 여기에 해당함.
- **로카드 교환법칙(Locard's exchange principle)**
	- 범죄자가 범죄현장을 드나들 때 무엇인가를 가지고 가되 반드시 흔적을 남긴다는 것.

#### 2) 포렌식의 기본 원칙
- **(가) 개요**
	- 증거가 법적 효력을 가질려면 발견하고, 기록하고, 획득하고, 보관하는 절차가 적절해야 함.
- **(나) 기본 원칙**
	- **정당성의 원칙**
		- 적법한 절차를 통해 획득한 것이어야 함
	- **재현의 원칙**
		- 똑같은 환경에서 같은 결과가 나오도록 재현이 가능해야 함.
	- **신속성의 원칙**
		- 휘발성 정보를 고려하여 신속하게 진행되어야 함
	- **연계 보관성의 원칙**
		- 증거를 획득하고 난 후 이송/분석/보관/법정 제출이라는 일련의 과정이 명확해야 하며 이러한 과정에 대한 추적이 가능해야 함. 이를 연계 보관성이라 한다.
		- 연계 보관성이 만족하려면 증거를 전달하고 전달받는 데 관여한 담당, 책임자를 명시해야 함.
	- **무결성의 원칙**
		- 수집된 정보는 위조, 변조 되어서는 안된다.
		- 하드의 경우 해시값을 구해 각 단계마다 그 값을 확인하며 무결성 입증이 가능.

#### 3) 포렌식 수행 절차
- **(가) 수사 준비**
	- 전문가 부르고 장비 준비
- **(나) 증거물 획득(증거 수집)**
	- 디지털 증거 획득하는 시기
	- 무결성이 매우 중요
	- 데이터를 추출하는 과정을 디스크 이미징이라고 함.
	- 디스크 복사와 달리 잔여정보가 그대로 존재하는 동일한 사본을 만듬.
- **(다) 보관 및 이송**
	- 보관/이송되는 곳은 안전한 장소, 즉 Evidence sage.
	- 이송되거나 담당/책임자가 바뀔 때는 문서에 증적을 남김
- **(라) 조사 및 분석**
	- 증거를 관리할 때는 최량 증거 원칙(The Best Evidence rule)을 따름.
		- writing, recording, photograph의 내용을 증명하기 위해서는 원본이어야 함
		- 원본 제출울 요구하는 영미 증거법상의 원칙.
	- 무결성을 유지시키면서 데이터 확인과정을 문서화 해야함.
	- 조사하고 분석하는 단계로서 디스크 브라우징, 데이터 뷰, 파일 복구 등 다양한 기법이 활용되고 있음.
	- **디스크 브라우징(Disk Browsing)**
		- 저장 매체 또는 디스크 이미지에 존재하는 파일을 GUI 환경에서 쉽고 편리하게 다룰 수 있도록 기억장치에 저장된 이진 데이터를 폴더, 파일 단위로 출력하는 등 수집한 저장 매체 또는 디스크 이미지 내부에 있는 정보를 가독성 있는 형태로 변환하여 출력하는 기술.
	- **데이터 뷰(Data Viewing)**
		- 저장 매체나 디스크에 저장된 방대한 파일을 열어서 확인할 수 없기 때문에 브라우징 과정에서 파일을 인식하여 텍스트, 그림 등의 형식으로 볼 수 있도록 하는 자동 뷰 기능을 제공하는 기술.
	- **파일 복구(File Recorver)**
		- 복구 소프트웨어를 이용하여 파일 원본을 복구시키는 기술로 파일 손상 또는 삭제되더라도 디스크 내에는 관련 정보가 보존되어 있기 때문에 파일 복구가 가능함.
- **(마) 보고서 작성**
	- 포렌식 모든 단계를 문서화 하는 단계. 
	- 알잘딱깔센있게 작성

#### 4) 포렌식 기술
- 디스크
- 시스템
- 네트워크
- 인터넷
- 모바일
- 데이터베이스
- 암호
- ...포렌식 기술이 존재

#### 5) 디지털 포렌식 도구
- EnCase : 가장 대표적인 도구
- FTK : Access Data Group에 의해 개발된 다용도 포렌식 도구.

#### 6) 역할
- **(가) 1차 대응자의 역할**
	- 교육 안받았으면 가장 먼저 도착한 사람은 컴퓨터 손상만 보호하고 그 외에는 아무것도 하지 말아야 함
- **(나) 수사자의 역할**
	- 범죄현장에서 일어나는 다른 모든 일을 조정할 책임을 가짐
- **(다) 범죄 현장 기술자의 역할**
	- 컴퓨터 포렌식 교육 받아라
	- 그냥 전문가여야 함

### (3) 증거
#### 1) 증거 규칙
- 증거를 제시할 법원이 위치한 그 지역 법을 따라야 함
- 증거 관련법에 익숙해져야 함

#### 2) 보호관리 사슬 = 증거 담당자 목록
- 증거 담당자 목록이란 증거의 연속성을 가리킴.
- 수집된 증거가 법정에 제출될 때까지 경로, 다룬 사람, 옮겨진 장소와 시간 등을 추적할 수 있어야 함
- 이걸 문서화 하는것은 증거 기록을 남기는 가장 중요한 목적의 하나.

#### 3) 디지털 증거물 분석
- **Timeline 분석(MAC time 분석) : 파일 생성, 변경, 접근, 삭제시간 등**
	- mtime : 파일 생성, 수정한 시간 
	- atime : 파일을 읽거나 실행시킨 시간
	- ctime : 파일 속성이 변경된 시간
- **시그니처 분석 :** 의도적으로 파일 확장자를 변경해 놓은 파일을 간단히 파악.
- **Hash 분석**
	- 시스템 내의 파일이 변경되었는가를 확인
	- 기존에 알려진 파일과 같은 파일이 존재하는가를 확인
- **로그 분석**
	- 웹 브라우저, 메일, FTP 로그 등
- **프로세스 분석**
	- 현재 수행되고 있는 프로세스의 메모리 내용을 조사, 의심되는 실행 파일 조사

#### 4) 사라지기 쉬운 데이터 보존
- 램 같은 시스템의 메모리에 저장된 정보는 휘발성 데이터. 전원이 나가면 저장된 데이터는 사라짐
- IEEE인터넷 드래프트인 Guidelines for Evidence Collection and Archiving이라는 글에서는 휘발성이 가장 큰 증거를 먼저 수집하라고 제시함.
	- 현재 네트워크 연결을 보기 위한 netstat등의 명령
	- arp 명령은 ARP 캐시에 어떤 주소가 저장돼 있는지를 알려줌 = 최근 누가 시스템에 연결했는지 알려줌

#### 5) 디지털 증거 보존
- 가장 좋은 방법은 증거가 저장된 매체의 완전한 비트스트림 이미지를 즉시 만드는 것.
- **비트스트림 이미지**
	- 원본 저장 장치에 기록됐던 모든 데이터의 사본. 이러한 데이터에는 모든 숨긴 파일, 손상된 파일, 파일 일부분과 삭제된 파일 중 아직 덮어 쓰이지 않은 파일 등이 있음. 모든 이진 데이터가 복사 매체에 그대로 복사된다. 
	- 비트스트림 백업이라고도 불림.
	- CRC 계산법을 이용해 원본 데이터와 차이가 없는지를 확인함.

### (4) 디지털 증거 복구
#### 1) 개요
- 자기 증거를 순순히 남기는 애들은 적음
- 안티 포렌식 : 데이터를 조작하거나 삭제, 난독화하여 조사를 어렵게 만들거나 시간이 많이 소요되도록 하거나 불가능하게 하여 포렌식을 방해하는 행위. 파괴외 은폐 두 가지로 나뉨. 파괴에는 내용을 깨끗이 지우는 와이핑, 자기장을 완전히 지우는 디가우징 기술을 사용하기도 함.

#### 2) 삭제된 데이터 복구
- 파일을 삭제한다고 디스크에서 사라지는게 아님
- 파일을 지우는건 file allocation table(FAT), master file table(MFT), 기타 운영체제에서 디스크의 파일의 위치를 기록하기 위해 사용하는 데이터 구조에서 항목 하나를 없애는 것에 불과함.

#### 3) 감춰진 데이터 찾기
- 중요한 데이터 중 일부는 삭제되거나 디스크가 다시 파티션 될 때 남아있던 주변 데이터. 
- 기술을 잘 아는 사이버 범죄자가 디스크 편집기, 스테가노그라피, 소프트웨어, 기타 방법을 이용해 고의적으로 데이터를 숨길 수 있는 여러 장소가 존재함.
- **데이터는 어디에 숨어 있는가?**
	- 디스크 섹터는 고정된 크기(예: 512바이트)의 공간 단이다. 오래된 하드디스크는 구조상(모든 트랙이 동일한 숫자의 섹터로 구성돼 있다) 외부 트랙 부분에 쓰지 않는 저장 공간이 있을 수 있고 그곳에 데이터를 숨기는 일이 가능하다. 이러한 공간을 섹터 갭(sector gap)이라고 한다. 
	- 클러스터와 파일크기가 서로 다르기 때문에 발생하는 슬랙공간에도 숨길 수 있다.

#### 4) 인터넷 임시파일
- 익스플로러를 통해 특정 사이트에 접속하게 되면 관련 사이트의 페이지는 임시 파일에 저장되며 접속한 흔적이 히스토리에 남음. 사용되었던 쿠키도 디스크에 저장됨.
	- **임시 인터넷 객체 :** `%SystemRoot%Downloaded ProgramFiles`
	- **임시 인터넷 파일 :** `%USERPROFILE%Local Settings\Temporary Internet Files`
	- **열어본 페이지 :** `%USERPROFILE%Local Settings\History`
	- **임시 쿠키 파일 :** `%USERPROFILE%Local Settings\COOKIES`

### (5) 데이터 복구 기법 피하기(Data Sanitization)
#### 1) 디스크 덮어쓰기
- 잔류 자기(Data remanence)라는 용어는 삭제된 파일의 데이터 중 물리적으로 디스크에 남아 있는 부분을 가리킴.
- 많은 상업용 또는 셰어웨어, 또는 무료 디스크 청소 유틸리티는 이런 잔류 데이터를 완전히 제거한다고 주장함. 근데 아닌가봄
- 디스크의 할당되지 않은 공간을 덮어쓰는 방식으로 동작함. 랜덤한 이진 값으로 할당되지 않은 공간을 덮어쓰는데 이를 여러 번 수행할 수 있음.

#### 2) 소자(Degaussing)
- 매체의 자기 상태를 중화시킬 수 있는 강력한 자기장을 만들수도 있다.

#### 3) 물리적으로 디스크 파괴
- 단순무식
- 분쇄, 소각, 연마/염산 처리(디스크 표면에 사포질이나 요오드화 수소산 용액을 붓기)
